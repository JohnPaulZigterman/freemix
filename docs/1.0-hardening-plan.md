# Freemix VM-420 1.0 Hardening Plan

This is the working checklist for turning the current app into a stable 1.0 foundation. The priority is dependable behavior, simple architecture, and easy future expansion.

## 1.0 contract

These behaviors are release blockers if they regress:

- Video always starts from the selected anchor.
- Retrigger timing follows one transport clock.
- Arrangement playback matches exported arrangement.
- Clip settings are per-clip, persistent, and editable.
- Stop stops all media and audio.
- Empty scenes produce silence/black.
- Every visible control reflects the selected target.
- Audio FX, drums, text, export, search, and media loading have clear ready/error states.

## Current architecture direction

- Transport is the single source of truth for timing.
- Arrangement clips are the source of truth for scene-specific behavior.
- Special tracks use the same selection/copy/paste/delete lifecycle as A/V clips.
- Drum playback uses pre-rendered one-shots for lightweight, stable scheduling.
- Export should mirror live playback instead of inventing a second interpretation of the arrangement.
